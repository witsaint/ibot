## 先区分实现与验收

OpenMuse 是有真实后端、持久化任务、浏览器 worker 和可选 Linux 容器的个人 agent alpha。它更适合参考完整应用流程；当前身份系统为一个部署一个 owner，不是可直接作为多租户服务使用的底座。登录成功后的 owner 固定为 `local-user`。[README](https://github.com/CopilotKit/openmuse/blob/d0b3a6b3ea461bc938a5dea6c46e65eefdb1b933/README.md#configure-the-agent-and-google)；[身份实现](https://github.com/CopilotKit/openmuse/blob/d0b3a6b3ea461bc938a5dea6c46e65eefdb1b933/apps/server/src/auth.ts#L15-L40)
