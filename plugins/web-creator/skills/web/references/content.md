# 内容与页面结构

## 从真实材料开始

记录：主题、读者、他们要理解/比较/操作的事情、已知事实、素材来源、主操作、未知项。已有对话里的材料直接复用。没有品牌设定时根据主题形成简短定位，不虚构公司背景。

内容和设计一起推进。写出实际标题、说明和操作文案后再排版；不使用 lorem ipsum 或“赋能未来”等空泛文案。主标题描述具体主题或价值，副标题补充对象与使用方式，按钮写出动作与结果。

## 首屏由用途决定

| 用途 | 首屏优先内容 | 后续内容举例 |
| --- | --- | --- |
| 活动/报名 | 活动名、时间地点、照片、报名入口 | 行程、适合谁、费用条件、交通、常见问题 |
| 报告/知识展示 | 结论、范围、来源、阅读入口 | 核心发现、图表、解释、方法、来源 |
| 作品集/个人介绍 | 身份、代表作品、图片 | 项目过程、能力证据、个人介绍、联系 |
| 产品介绍 | 能解决什么、真实演示、试用入口 | 具体场景、使用步骤、功能证据、限制 |
| 实用工具 | 输入与结果或可立即尝试的示例 | 使用说明、边界、失败提示 |

不用固定首屏大字+三个卡片，也不强制每个网页都包含痛点、定价和营销 CTA。长文章可以优先目录与排版；工具可以直接显示操作区域。

## 区块安排

每个区块只负责一个问题，提供新信息。删掉重复卖点。根据材料选择图片、时间轴、地图、引文、对比表、图表、演示、表单或纯文字；没有足够内容不硬填区块。重要信息放在操作前，辅助说明允许展开。

为交互写清楚默认、加载、错误、空、完成状态。错误说明如何恢复，按钮描述具体动作，长中文标题不因换行失去含义。

## 提升表达质量

先检查事实与阅读顺序，再检查信息层级，再调整语言与视觉细节。用具体事物和可信材料替代形容词。保持同一术语、语气和时间格式。只有真实存在的证据才进入评价、数据和客户区块。

本文件借鉴内容规划、copywriting/copy-editing、Impeccable shape/clarify 的分析方法，未包含其强制确认步骤或完整营销结构。
