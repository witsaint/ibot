# 按内容寻找与组合设计

1. 提炼检索条件：网站用途、受众、视觉感受、内容密度、图片比例、中文长度、手机优先级、主要操作、动效强度。不要仅按行业搜索。
2. 优先用 search_design_styles 搜索 2–3 个视觉与内容关键词，按需用 get_design_style 读取所选候选。另需特定区块时从 resources.md 选补充来源。有浏览器时查看少量候选的实际页面；API 数据不能替代浏览检查，无法看到的部分标为未知。
3. 评估内容适配、主操作清晰度、排版层级、媒体需求与实现难度。漂亮但依赖大量缺失照片的参考不是合适默认选项。
4. 选择一个主要方向统一区块和 tokens。补充参考只负责具体需要，例如目录、对比表或报名表。不要拼接多套字体、圆角和颜色。
5. 获取 DESIGN.md 时记录来源、取得日期、官方/社区性质与许可；实际预览和内容适配优先于文档的完整程度。没有取得文档就自行写项目规范，不声称直接复用。
6. 用真实首屏内容验证所选方向，修正标题长度、图文比例、主要操作，再落实项目 design.md。

## 审美检查

- 明确主次，有一处视觉重点；克制强调色，字号与留白形成阅读顺序。
- 根据内容选择编辑排版、图片浏览、信息比较或操作界面，避免把所有内容塞进同类卡片。
- 中文字体具有完整字形，正文长度与行高可读。复用一致的间距与组件，不随区块更换装饰风格。
- 动效解释变化或提供反馈，尊重 reduced motion，不延迟主要内容出现。
- 用户指定的风格和已有项目规范优先。不要把“不准渐变/不准紫色”等泛化禁令当作品味判断。
- 仅按当前阶段使用一个主要视觉指导。其他技能只取针对问题的排版、文案、检查部分，冲突时以用户要求和项目 design.md 为准。
