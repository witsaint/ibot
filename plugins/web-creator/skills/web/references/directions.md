# 六个场景方向

这是自编的内容与布局起点，不是六套固定配色或完整网站模板。用户明确的视觉要求优先；可以组合内容结构，但全页只使用一套颜色、字体与组件变量。

| 方向 | 适用内容 | 优先考虑 | 避免 |
| --- | --- | --- | --- |
| 内容阅读 | 个人报告、观点、指南、知识整理 | 清晰目录、适合中文的行宽与行高、段落层次、引用及图表 | 将长文拆成大量相同卡片、装饰压过结论 |
| 资料比较 | 产品比较、方案选择、研究结果 | 统一比较维度、表格或并排布局、关键差异、来源、筛选 | 未知值填成零、颜色替代文字说明 |
| 轻量工具 | 清单、计算器、查询和小型操作界面 | 尽早显示操作入口、字段标签、输入与结果、空/失败/加载状态 | 营销首屏挤占操作、假成功、重装饰 |
| 作品展示 | 作品集、摄影、项目成果 | 真实素材、主作品突出、媒体比例、短说明、浏览节奏 | 缺失素材仍选择依赖大图的方向、挪用品牌作品 |
| 活动介绍 | 聚会、活动、课程、服务介绍 | 谁适合、能获得什么、安排与地点、真实参与方式 | 编造评价/时间/名额、没有服务却显示报名成功 |
| 自然生活 | 徒步、旅行记录、生活主题 | 自然色彩、内容留白、真实路线或明确示例、必要的地图与数据 | 用氛围图掩盖信息、泛化旅行营销文案 |

## 如何选择

1. 判断读者主要在阅读、比较、浏览作品还是完成操作，先定内容方向；行业只是补充条件。
2. 判断正文长度、素材是否齐全、中文占比、手机使用比例和主要操作。
3. 用户指定视觉风格则沿用；未指定时根据上述条件提出一个适合的视觉方向并继续，不要求用户逐项选颜色。
4. 需要具体参考时从 resources.md 选来源，实际查看少量候选。不得把本表当成已经取得外部规范。
5. 用真实首屏和一个代表性的后续区块检验方向。写入 design.md 的都是本项目实际决定；没有采用的建议不写成项目禁令。
