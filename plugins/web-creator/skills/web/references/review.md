# 交付前检查

按内容意义 → 实际使用 → 视觉细节的顺序修复，避免只有截图看起来完整。

## 内容
主题一眼可理解；首屏有真实信息；后续区块提供新增价值；标题/正文/操作相符；数字与引用有来源；示例与未知项标明；没有空泛重复宣传。

## 显示
实际检查约 390px 手机与约 1440px 桌面；长标题、中文字体、溢出、图片裁切、留白、层级、对比度一致。必要时看中间宽度。观察加载完成后的实际页面，不只看源代码。

## 操作
点击主操作和导航；表单检查空值、错误、成功或待接入状态；键盘可操作，焦点可见；主操作在手机可触达；链接不是占位 #；刷新后行为符合保存能力。只测项目实际具有的功能。

## 运行
构建通过；实际页面没有阻断使用的控制台错误；资源加载可达；预览 URL 与进程仍有效；design.md 描述与实现一致。网页可打开不等于后端功能真实接通。

## 交付
给一个可用预览入口、简短结果说明、主要操作和实际限制。无需展示内部技能清单或所有草稿。用户修改时读取项目 design.md，继续用真实材料迭代；需要再次调用整个创作流程时使用 `/web`。
