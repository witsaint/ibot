面向多租户的 Computer-Use Bot 平台

对标 Grok Bot:每个用户创建独立 bot,每个 bot 由一个隔离的 PPIO Sandbox(Xvfb + Chrome + overlay 磁盘)承接。本文给出核心洞察、三层架构、技术选型、编排层决策,以及 computer-use × browser-use 的融合实现路径。

PPIO Sandbox Vercel AI SDK v5 NestJS 12 Next.js 16 Turborepo 2.10 Railway

来源分级:标注「已验证」的结论来自对本地 ppio-sandbox SDK 源码的直接阅读;其余来自 xAI/官方文档与 2026 年第三方资料,计费与版本以官方页面为准。

00核心洞察

你不需要自己造执行层。

PPIO Sandbox SDK 就是 Grok Bot computer-use 那套执行层的开源等价物,而且 E2B 兼容。本地的 agent-sandbox-sdks-ppio 与已发布的 ppio-sandbox@1.1.3 已经把 Grok Bot 口述的整套能力封装完毕。

已验证 · 源码级

ppio-sandbox/desktop 导出完整 18 个桌面动作(screenshot / leftClick / drag / mousePress / mouseRelease / scroll / write / press …),内置 VNCServer 流用于人机接管。sandbox 内任意端口经 getHost(port) 自动映射为公网子域名 —— 这正是 CDP 口与 noVNC 预览被外部访问的机制。

因此工程重心不在「搭 Xvfb / VNC / CDP」,而在 决策层(agent 编排)+ Web(多租户产品)。你的服务 = Grok 的「对话宿主」,PPIO Sandbox = 「云电脑」,中间用 SDK 通信。

03编排层:AI SDK vs Codex

这是全局最关键的一个二选一。

两个候选:后端用 Vercel AI SDK 远程驱动 sandbox 工具,或每个 sandbox 内跑 OpenAI Codex CLI。

维度 AI SDK(后端) Codex(sandbox 内)
并发 一进程 N 个异步循环,context 隔离 每租户一个 codex app-server 子进程,更重
Provider Anthropic + OpenAI 可换(AI Gateway) 锁定 OpenAI
Computer-use 契合 computer_* 为 client-executed,映射远程执行 桌面 app / 像素向,非无头 Linux 浏览器
流式 UX toUIMessageStreamResponse + useChat 原生 需自行把 runStreamed 事件翻成 SSE
成本 / 可观测 自控 loop、模型、stopWhen 步数;OTel span 内部 loop 对 token/步数更不透明

决策

后端用 Vercel AI SDK 驱动远程 sandbox 工具。 Codex 仅作为可选的「sandbox 内编码专家」(@openai/codex-sdk / MCP)保留给做软件任务的 bot,编排主干仍是 AI SDK。

Agent loop 用 generateText/streamText 的 stopWhen: stepCountIs(n) 控制多步(替代旧 maxSteps);computer-use 场景把上限提到 100+。工具用 tool({ description, inputSchema: z.object(...), execute }) 定义,execute 把动作转发给远程 sandbox 并回传截图。

注意 · open-codex-computer-use

iFurySt/open-codex-computer-use 是一个走「accessibility API + 截图」的 MCP server,面向桌面 accessibility,未见确认的 Xvfb 无头 Linux 工作流。可作为「把 Codex 接到 computer-use」的参考模式,不是多租户生产可直接落地的组件。

04Computer-Use × Browser-Use 融合

同一块 $DISPLAY 上,DOM 操作与像素操作会抢屏。

核心矛盾:CDP(DOM)与像素(截图+坐标)控制同一屏。解法是分工 + 单一控制者 —— 按任务类型路由到三条路径之一,同一时刻只有一个桌面控制者。

Browser-Use 首选 · CDP

网页任务:点按钮、填表、导航、读 DOM。经 Chrome 远程调试口,快、稳、不靠坐标。

→ Playwright/CDP client 连 9222-{id}.sandbox.ppio.cn

Computer-Use 兜底 · 像素

系统级:原生密码框、文件对话框、滑块验证码。截图 → 坐标 → 动作。

→ desktop.screenshot() + leftClick/drag

Human Handoff 接管 · VNC

登录 / 扫码 / 过验证。VNC 全屏交给人,agent 本轮暂停派屏,交还后再截图感知。

→ stream.getUrl({ viewOnly:false })

滑块验证码 = press → move(分段) → release

// 你特意问的滑块:本质是一段带节奏的 drag,失败重截图重试
const { width, height } = await desktop.getScreenSize()
await desktop.moveMouse(startX, startY)
await desktop.mousePress('left')
for (const x of segments(startX, targetX)) {   // 分段 + 抖动,拟人
  await desktop.moveMouse(x, startY + jitter())
  await desktop.wait(rand(12, 40))
}
await desktop.mouseRelease('left')
const shot = await desktop.screenshot()        // 校验成功,否则重试

同屏互斥规则

Browser(CDP)与 Desktop(像素)共用一块 $DISPLAY。同一时刻只允许一个桌面控制者。人接管时,agent 本轮不得再派桌面点击;人交还后,agent 下一轮靠截图/读 DOM 才能「看见」变化。

05多租户模型

一个 bot ↔ 一个 sandboxId。

「每人独立 bot、每 bot 独立空间」在 sandbox 层天然成立:Sandbox.create('desktop', …) 每次产出隔离实例,有独立 sandboxId、独立 overlay 磁盘、独立 Chrome profile。平台侧维护 bot ↔ sandboxId 映射与生命周期。

状态 触发 动作
create 用户新建 bot / 首次对话 按自定义模板拉起 sandbox,记 sandboxId,启动 VNC 流
active 对话中 / agent 循环执行 后端持 SDK 句柄驱动;工具结果流式回 Web
idle → pause 超时无活动 暂停 sandbox 省成本;保留 overlay 磁盘与登录态
resume 用户回来 / webhook 唤醒 恢复实例,重连 CDP/VNC
kill 删除 bot / 长期不用 回收 sandbox;持久数据落 DB/对象存储

成本 / 隔离

每个活跃 bot 是一台真实云桌面 —— 成本随并发 bot 数线性增长。idle 自动暂停 + 池化预热是控成本关键。绝不跨租户共享 sandbox;sandbox 的 envd access token 绝不落日志。

自定义环境:CLI 的 template build/publish(基于 Dockerfile)可预装飞连、lark-cli 等,做成你自己的基础镜像。

安全红线

控制面暴露 sandbox 编排与 webhook。每条 API 路由从第一天起就鉴权,webhook 先验签再干活。绝不上线无鉴权的控制面。

07风险与未验证项

如实标注,不掩盖。

未验证 · 脚手架

上一轮搭 monorepo 骨架时,工具通道一度返回异常(Write 结果被追加杂讯、幽灵临时文件、Bash 空输出)。已写入的根配置与 types/config 包极可能落盘但未逐一复核内容;packages/types/src/* 与整树 pnpm install / build 尚未验证。下一轮通道正常时需 find + 安装构建一次性确认。

  • 成本模型未量化:每活跃 bot = 一台云桌面。需实测 PPIO 单 sandbox 计价 + idle 暂停/恢复延迟,才能定价与容量规划。
  • 第三方版本漂移:AI SDK v6 已于 2025-12 announced;Railway config-as-code 2026-12-01 弃用。落地前对官方文档二次确认。
  • 反自动化对抗:滑块/行为验证码是持续对抗,拟人拖拽不保证通过率;高价值站点优先设计 human-handoff 兜底。
  • 私有协议不可见:PPIO 宿主网关(如 1340 端口)的报文格式、鉴权、内部任务队列是产品内部实现,SDK 之下的细节看不到,不臆造。
